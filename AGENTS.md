# Repository instructions

## Purpose and scientific boundary

This repository studies differentiable trajectory tracking through Crazyflow's pure JAX
Mellinger controller and pure JAX dynamics. Smooth reference setpoints are rolled out with
`jax.lax.scan`, and a scalar tracking loss is differentiated with `jax.value_and_grad`.

The native C/C++ Mellinger bridge is a completed validation proof. It does not belong in this
repository and must never be introduced into the gradient path. Results here are simulation
evidence, not complete physical, firmware, or hardware validation.

## Required Python environment

The repository runs under WSL and uses the repository-local `.venv/`. Do not assume activation.
Every automated Python command must explicitly use:

- `.venv/bin/python`
- `.venv/bin/python -m pytest`
- `.venv/bin/python -m pip`

Do not use unqualified `python`, `pytest`, or `pip`. Optional interactive activation with
`source .venv/bin/activate` does not relax this rule for automation.

## Analysis exclusions

- Do not routinely analyze or modify `crazyflow/drones/assets/*.stl`, `docs/img/`, or old PNG
  artifacts.
- Exclude binary files, caches, generated bytecode, and environment caches from source analysis.
- Do not ignore the complete `artifacts/` tree: reproducible JSON and plot evidence belongs there.
